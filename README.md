## Installation

### From VS Code Marketplace
1. Open VS Code
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Type `ext install digitalforge.09d9f3ee`
4. Press Enter

### From VSIX file
1. Download the `.vsix` file
2. In VS Code: `Extensions > ··· > Install from VSIX`
3. Select the downloaded file

## Usage

Press `Ctrl+Shift+P` and search for `MCP Servers & Tools Code Snippets and Boilerplate Generator VS Code Extension` to see all available commands.

**Keyboard shortcut:** `Ctrl+Shift+Alt+A` (or `Cmd+Shift+Alt+A` on Mac)

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `09d9f3ee.enabled` | `true` | Enable/disable the extension |
| `09d9f3ee.autoRun` | `false` | Auto-run on file open |
| `09d9f3ee.logLevel` | `"info"` | Log verbosity |
